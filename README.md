# 3dsuika
Unofficial complete Suika Game demake for Nintendo 3DS systems.
<img width="1280" height="720" alt="suika preview" src="https://github.com/user-attachments/assets/7435965a-4d54-4e41-999f-8124a858ca7c" />

## What you need

- Any 3DS or 2DS system with custom firmware (Luma3DS) and FBI.
- About 40mb free on the SD card.
  
## AI Usage

AI was used to create tools to work with Nintendo proprietary 
image format so the banner image could be crated. Rest of 
the project is made by human
